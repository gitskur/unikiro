POST /chat 의사결정 트리
POST /chat 수신
│
├─ ① message 비어있음?
│   ├─ YES → HTTP 400 반환
│   └─ NO  → 계속
│
├─ ② 입력 길이 > 8000자?
│   ├─ YES → 8000자 truncate
│   └─ NO  → 원본 사용
│
├─ ③ DynamoDB 히스토리 조회 성공?
│   ├─ YES → 최근 3턴 컨텍스트 추가
│   └─ NO  → 히스토리 없이 계속 (폴백)
│
├─ ④ 계약번호 추출됨?
│   ├─ YES → Coupa API 호출
│   │   ├─ Coupa 응답 성공?
│   │   │   ├─ YES → Coupa 컨텍스트 추가
│   │   │   └─ NO  → Coupa 컨텍스트 없이 계속 (타임아웃 폴백)
│   └─ NO  → FAISS 검색만 사용
│
├─ ⑤ FAISS 유사도 임계값 통과?
│   ├─ YES → 관련 chunks 컨텍스트 추가
│   └─ NO  → "해당 정보를 찾을 수 없습니다" 반환
│
├─ ⑥ Bedrock 호출 성공?
│   ├─ YES → HTTP 200 + 답변 반환
│   └─ NO  → HTTP 500 반환
│
└─ ⑦ Lambda 60초 초과?
    └─ YES → HTTP 504 반환
POST /coupa/webhook 의사결정 트리
POST /coupa/webhook 수신
│
├─ ① status == 'draft'?
│   ├─ YES → HTTP 200 (알림 미발송)
│   └─ NO  → 계속
│
├─ ② 만료일 D-60 이내?
│   ├─ YES → ChannelMapping 조회
│   │   ├─ 매핑 존재?
│   │   │   ├─ YES → 해당 채널 Webhook URL 사용
│   │   │   └─ NO  → TEAMS_DEFAULT_WEBHOOK_URL 폴백
│   │   └─ Teams Adaptive Card 발송
│   └─ NO  → HTTP 200 (조건 미충족)

POST /teams 수신
│
├─ ① type == 'conversationUpdate'?
│   ├─ YES → HTTP 200 (무시)
│   └─ NO  → 계속
│
├─ ② message 비어있음?
│   ├─ YES → HTTP 400
│   └─ NO  → /chat 로직과 동일하게 처리
│
└─ Teams 응답 메시지 반환
