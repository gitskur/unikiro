데이터 흐름 요약
[ Teams 채널 ]
  직원 Teams 메시지
  → Azure Bot Service → POST /prod/teams { activity }
  → Lambda handle_teams() → S3 파싱(캐싱) → Bedrock
  → reply activity → Teams 채팅에 봇 답변 표시

[ Chat UI 채널 ]
  index.html 입력
  → API Gateway POST /prod/chat { messages[] }
  → Lambda → S3 파싱(캐싱) → Bedrock → { reply }
  → marked.parse(reply) 렌더링
알고리즘 상세 흐름
🟦 Teams 채널 (엔드유저 경로)
1

👩‍💼 직원 → Teams 메시지 입력

사내 Teams 채팅에서 봇에게 메시지 전송
Azure Bot Service가 수신 → Activity { type:"message", text:"..." } 생성

▼
2

📡 Azure Bot → POST /prod/teams

Azure Bot Service가 Lambda 웹훅 URL로 Activity JSON 전달
Lambda handle_teams(activity) 호출

▼
3

📂 S3 문서 로딩 + 파싱 (캐싱)

_doc_cache 확인 → 없으면 S3 manuals/ 파일 다운로드
.pdf → pypdf 텍스트 추출 / .pptx → python-pptx 슬라이드 추출

▼
4

🤖 Bedrock Claude 호출

system: 매뉴얼 문서 전체 + 역할 지시
messages: [{ role:"user", content: activity.text }]
모델: claude-3-sonnet-20240229-v1:0 / max_tokens: 1024

▼
5

💬 reply activity 반환 → Teams 표시

{ type:"message", text: reply, textFormat:"markdown" } 반환
Azure Bot Service가 Teams 채팅에 봇 답변으로 표시

🟥 Chat UI 채널 (개발/테스트 경로)
1

🧑‍💻 index.html → 질문 입력

messages[]에 추가 → fetch(API, { body: { messages } })

▼
2

📡 POST /prod/chat → Lambda → Bedrock

동일한 S3 파싱 + Bedrock 호출 로직 재사용
{ reply: "마크다운 텍스트" } 반환 → marked.parse() 렌더링
