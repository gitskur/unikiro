POST /chat AI 챗봇 질의응답 ▶
Request Body
// Content-Type: application/json
{
  "message": string,        // required — 사용자 질문
  "user_id": string         // optional — 사용자 식별자
}
Response 200
{
  "answer":    string,        // AI 응답 텍스트
  "timestamp": string,        // ISO 8601
  "sources":   string[]       // 참조 문서 목록
}
Error Responses
400 500 
// 400 Bad Request
{ "error": "message required" }

// 500 Internal Server Error
{ "error": string }
GET /health 헬스체크 ▶
Response 200
{ "status": "ok" }
POST /teams Microsoft Teams Bot Framework ▶
Request Body — Bot Framework Activity
{
  "type": string,           // e.g. "message"
  "text": string,           // 사용자 메시지
  "from": {
    "id":   string,
    "name": string
  },
  "id": string              // activity ID
}
Response 200
{
  "type":       "message",
  "text":       string,        // AI 응답 (Markdown)
  "textFormat": "markdown",
  "replyToId":  string         // 원본 activity ID
}
POST /coupa/webhook Coupa 계약 상태 알림 ▶
Request Body — Coupa Contract Object
{
  "id":        number,
  "name":      string,
  "status":    string,        // 아래 알림 대상 참조
  "stop_date": string,        // ISO 8601 date
  "contract-owner": {
    "email":    string,
    "fullname": string
  },
  "supplier": {
    "name": string
  }
}
알림 발송 대상 Status
approved rejected cancelled pending_approval
Response 200
{ "status": "ok" }
POST /coupa/approval-webhook Coupa 결재 상태 알림 ▶
Request Body — Coupa Approvals Object
{
  "id":               number,
  "status":           string,   // 아래 알림 대상 참조
  "approver": {
    "email":    string,
    "fullname": string
  },
  "approvable-type":  string,   // e.g. "Contract"
  "approvable-id":    number,
  "position":         number
}
알림 발송 대상 Status
approved rejected
Response 200
{ "status": "ok" }
