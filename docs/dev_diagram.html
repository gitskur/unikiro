배포 파이프라인
1
build_layer.bat — Lambda Layer 빌드

Docker (Amazon Linux 2) 환경에서 pypdf, python-pptx 패키지 빌드 → layer.zip 생성 → aws lambda publish-layer-version

docker run public.ecr.aws/lambda/python:3.12 pip install -r requirements.txt aws lambda publish-layer-version --layer-name coupa-ai-deps ... → 출력: Layer ARN
2
deploy_infra.bat — CloudFormation 스택 배포

S3 버킷 + IAM Role + Lambda 함수 + API Gateway 한번에 생성

aws cloudformation deploy \ --template-file infra/cloudformation.yaml \ --stack-name coupa-ai-facilitator \ --parameter-overrides LayerArn=<ARN> BotPassword=<PW> \ --capabilities CAPABILITY_NAMED_IAM → 출력: ApiUrl, TeamsWebhookUrl, DocsBucketName
3
Lambda 코드 배포

lambda_function.py를 zip으로 압축 후 업로드

Compress-Archive lambda_function.py function.zip aws lambda update-function-code \ --function-name coupa-ai-facilitator \ --zip-file fileb://function.zip
4
S3 매뉴얼 업로드

PDF/PPT 매뉴얼 파일을 S3 manuals/ 폴더에 업로드

aws s3 cp 구매프로세스.pdf s3://coupa-ai-docs-{id}/manuals/ aws s3 cp 계약가이드.pptx s3://coupa-ai-docs-{id}/manuals/ → Lambda 다음 콜드스타트 시 자동 반영
5
Azure Bot 웹훅 등록

Azure Portal에서 Bot Service 생성 후 Messaging Endpoint 설정

Messaging endpoint: https://<api-id>.execute-api.us-east-1.amazonaws.com/prod/teams Teams 채널 연결 → 직원들이 Teams에서 바로 사용 가능
6
Chat UI 연결 (테스트)

index.html의 API URL 교체 후 브라우저에서 테스트

// ui/index.html const API = 'https://<api-id>.execute-api.us-east-1.amazonaws.com/prod/chat';
