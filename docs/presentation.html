Tech Stack

기술 스택 상세

🤖 AI/ML

  • Amazon Bedrock — Claude 3 (nova-lite-v1:0)
  • FAISS — 벡터 유사도 검색 (IndexFlatIP)
  • Titan Embed v2 — 1024차원 임베딩
  • pypdf — PDF 텍스트 추출

☁️ AWS 인프라

  • Lambda — Python 3.9, 3개 함수 (RAG/스케줄러/웹훅)
  • API Gateway — REST API (5개 엔드포인트)
  • DynamoDB — 2개 테이블 (대화기억/채널매핑)
  • S3 — 문서 저장소 + FAISS 인덱스
  • EventBridge — Cron 스케줄러 (매일 09:00 KST)
  • SAM — IaC 배포 (template.yaml)

🔗 외부 연동

  • Microsoft Teams — Bot Framework SDK
  • Azure Bot Service — 봇 등록 및 인증
  • Coupa REST API — 계약/PO 조회, Webhook 수신

🎨 프론트엔드

  • Chat UI v5 — Vanilla JS, marked.js (마크다운)
  • 드래그 이동 — mousedown/mousemove 이벤트
  • 숨기기/복원 — localStorage 상태 저장
  • 화면 이탈 방지 — boundary 체크
Roadmap

향후 계획

Phase 1 — 즉시 (1~2주)

TC-19 개선 (PO 번호 없는 질문 처리) · 청크 전략 최적화 · 프롬프트 튜닝

Phase 2 — 단기 (1개월)

지식베이스 확장 (추가 정책 문서) · 사용자 피드백 루프 · 답변 품질 모니터링 대시보드

Phase 3 — 중기 (3개월)

Coupa 액션 실행 (PO 생성/승인 요청 자동화) · 다국어 지원 · 사용 통계 분석 및 ROI 측정

Phase 4 — 장기 (6개월+)

타 ERP 시스템 연동 확장 (SAP, Oracle) · Fine-tuning 검토 · 전사 AI 어시스턴트 플랫폼으로 발전
