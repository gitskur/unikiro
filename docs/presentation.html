Demo

데모 시나리오

시나리오 1 — 구매 절차 문의

사용자 입력

"850만원짜리 예산 내 구매야. 결재 누구한테 받아야 해?"

봇 답변

100만~1000만원 구간 → 팀장 → 구매팀 순서로 승인
필요 서류: 구매요청서(A-01), 견적서 2개

시나리오 2 — 긴급 구매

"오늘 당장 장비 사야 하는데 긴급 구매 가능해?"

팀장 구두 승인 → 구매 진행 → 영업일 3일 내 사후 서류 제출

시나리오 3 — 계약 연장

"기존 업체랑 계약 연장하려면 뭐 필요해?"

계약연장요청서(C-02) + 기존 계약서 사본
※ 500만원 이상 시 법무팀 검토 필수

시나리오 4 — 예산 외 구매

"예산이 부족한데 예산 외 구매는 어떻게 해?"

예산변경신청서(B-01) → 재무팀 승인 → 일반 구매 프로세스

배포 절차

Step 1 — build_layer.bat 실행 → Layer ARN 확보
Step 2 — deploy_infra.bat 실행 → API URL 확보
Step 3 — Bedrock 콘솔에서 Claude 3 Sonnet 활성화
Step 4 — S3에 PDF/PPT 업로드
Step 5 — Azure Bot Service 등록 → Teams 채널 연결
Step 6 — Chat UI에 API URL 설정 후 배포
