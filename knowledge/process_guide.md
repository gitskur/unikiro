# 구매 · 비용처리 프로세스 가이드

---

## 1. 구매 요청 프로세스

### 공통 사항
- 시스템: **Coupa** (Coupa Catalog에 등록된 항목 사용)
- 필수 첨부 서류:
  - **견적서** (아래 중 해당하는 종류로 첨부)
    - 단가 견적서: 제품/소프트웨어 등 단가 기반 구매 시
    - 유지보수 견적서: 기존 장비/시스템 유지보수 계약 시
  - **Max Spend 산정 금액**
- 계약 연장도 신규 구매와 동일한 프로세스 적용

---

### 1-1. On-Budget (예산 내)

#### 1000만원 미만
- 결재 라인: 팀장 → 본부장
- 시스템: Coupa Catalog
- 첨부 서류: 견적서, Max Spend 산정 금액

#### 1000만원 이상
- 결재 라인: 팀장 → 본부장 → 구매거래위원회
- 시스템: Coupa Catalog
- 첨부 서류: 견적서, Max Spend 산정 금액

---

### 1-2. Off-Budget (예산 외)

#### 200만원 이하
- 결재 라인: 팀장 → 본부장
- 시스템: Coupa Catalog
- 첨부 서류: 견적서, Max Spend 산정 금액

#### 200만원 초과 ~ 1000만원 이하
- 결재 라인: 팀장 → 본부장 → CFO
- 시스템: Coupa Catalog
- 첨부 서류: 견적서, Max Spend 산정 금액

#### 1000만원 초과 ~ 1억원 이하
- 결재 라인: 팀장 → 본부장 → CFO → CEO
- 시스템: Coupa Catalog
- 첨부 서류: 견적서, Max Spend 산정 금액

#### 1억원 초과
- 결재 라인: 팀장 → 본부장 → CFO → CEO → Global CFO
- 시스템: Coupa Catalog
- 첨부 서류: 견적서, Max Spend 산정 금액

## 2. 계약 체결 전체 프로세스 (단계별)

```
[1단계] Coupa 구매 요청
  → Catalog에서 항목 선택 후 구매 요청서 작성
  → 견적서(단가/유지보수) + Max Spend 산정 금액 첨부
  → 금액/예산 기준에 따른 결재 라인 승인

[2단계] 법무팀 계약서 작성
  → Coupa 구매 요청 승인 완료 후
  → 해당 계약 건을 법무팀에 전달
  → 법무팀에서 계약서 초안 작성

[3단계] 인감사용 신청
  → 전자결재시스템에서 인감사용 신청서 작성
  → 승인 완료 후 날인 진행 가능

[4단계] 날인 및 계약 완료
  → 자사 법무 날인
  → 타사 법무 날인
  → 계약서 최종 완료
```

- 시스템: **Concur**
- Concur에서 경비 보고서(Expense Report) 작성 후 제출
- 영수증 첨부 필수

## 3. 자주 묻는 질문 (FAQ)

**Q. Coupa 작성 후 다음 단계는?**
A. Coupa 구매 요청 승인 완료 후 아래 순서로 진행됩니다.
1. 법무팀에 계약 건 전달 → 계약서 초안 작성
2. 전자결재시스템에서 인감사용 신청서 작성 및 승인
3. 자사 법무 날인 → 타사 법무 날인 → 계약 완료

**Q. 구매 요청은 어디서 해?**
A. Coupa에 접속 후 Catalog에서 항목을 선택해 구매 요청서를 작성하세요.

**Q. On-Budget과 Off-Budget 차이가 뭐야?**
A. On-Budget은 사전에 승인된 예산 범위 내 구매, Off-Budget은 예산 외 추가 구매입니다. Off-Budget은 금액에 따라 CFO, CEO, Global CFO 추가 결재가 필요합니다.

**Q. 어떤 견적서를 첨부해야 해?**
A. 구매 유형에 따라 다릅니다.
- 제품/소프트웨어 등 단가 기반 구매 → **단가 견적서**
- 기존 장비/시스템 유지보수 계약 → **유지보수 견적서**

**Q. Max Spend 산정 금액이 뭐야?**
A. 해당 구매 건에서 발생할 수 있는 최대 예상 금액입니다. 견적서와 함께 첨부해야 합니다.

**Q. 계약 연장도 신규 구매와 같은 프로세스야?**
A. 네, 계약 연장도 신규 구매와 동일한 결재 라인과 첨부 서류가 필요합니다.

**Q. 경비 처리는 어디서 해?**
A. Concur 시스템에서 경비 보고서를 작성하고 영수증을 첨부해 제출하세요.

**Q. 구매거래위원회 결재는 언제 필요해?**
A. On-Budget 기준 1000만원 이상 구매 시 구매거래위원회 결재가 추가로 필요합니다.
